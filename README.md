# Comparateur de Prompt

Comparateur de Prompt est une application de bureau pensée pour comparer rapidement plusieurs formulations de prompts afin de choisir la meilleure réponse, selon les besoins de votre travail. Simple à prendre en main, elle est conçue pour être utilisée sans besoin de connaissances particulières en informatique.

Cette application permet de tester et d'évaluer différents prompts, notamment pour des usages liés à l'intelligence artificielle et aux modèles de langage, afin de gagner du temps et de mieux comparer les résultats.

## 🚀 Installation

### Méthode simple

1. Téléchargez le programme depuis le dépôt GitHub du projet.
2. Ouvrez le fichier téléchargé et extrayez le dossier sur votre ordinateur.
3. Dans le dossier extrait, double-cliquez sur l'icône de l'application pour la lancer.
4. Si votre ordinateur affiche un message de sécurité, confirmez l'ouverture si vous êtes sûr du fichier téléchargé.

> L'application est prévue pour être lancée simplement en double-cliquant sur l'icône du bureau ou dans le dossier où elle a été installée.

## 📥 Utilisation

### Étapes simples

1. Ouvrez l'application.
2. Saisissez ou sélectionnez les prompts que vous souhaitez comparer.
3. Ajoutez les paramètres ou options nécessaires selon votre besoin.
4. Lancez la comparaison.
5. Consultez les résultats affichés pour comparer les réponses obtenues.
6. Choisissez le prompt qui donne le meilleur résultat pour votre usage.

### Astuce

Vous pouvez utiliser cet outil pour tester plusieurs formulations avant de choisir celle qui convient le mieux à une tâche précise, comme la rédaction, la synthèse, ou l'analyse de texte.

## 🛠️ Fonctionnalités

- Comparaison rapide de plusieurs prompts
- Interface simple et claire pour un usage quotidien
- Compatible avec un usage en bureau sans connaissances techniques
- Possibilité de tester différentes formulations facilement
- Visualisation des résultats pour faciliter le choix
- Idéal pour comparer des approches avant de valider un prompt final
- Logiciel pensé pour gagner du temps dans les tâches répétitives
